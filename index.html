How to Install on iPad

Cloud PWA or Native .IPA
  • 01
    Add to Home Screen (No PC): Tap Launch App on any card above in Safari, tap the Share icon, and choose Add to Home Screen for a fullscreen app icon.
  • 02
    Native .IPA Sideload (Optional): Tap .IPA on any card (or visit GitHub Releases) to install with Feather, ESign, SideStore, or Sideloadly.
  • 03
    Automatic Weekly Updates: Synced every Sunday from @storytold. Tap ⚙️ → 🔄 inside any app to pull the latest version on demand.

iPadOS Touch & Desktop Controls

Zero Desktop Interference
  • ✦
    100% Desktop Mouse & Keyboard: Magic Keyboard, trackpad, hover states, right-click, and shortcuts work identically to macOS and Windows.
  • ✦
    Draggable Tool Dock (⚙️) & Gestures: Use 2-finger tap for Undo, 3-finger tap for Redo, 2-finger pinch to zoom, or tap the draggable ⚙️ pill for quick actions.
  • ✦
    Native iPadOS Files Integration: Exporting files automatically opens the native iPadOS Save to Files / Share Sheet (iCloud Drive, On My iPad, AirDrop).
