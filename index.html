03 / iPadOS Touch & Desktop Architecture
Zero Interference with Mouse, Trackpad & Physical Keyboard

Built for touch when you hold it.
Pure desktop when you dock it.

Every iPadOS upgrade runs inside a passive overlay layer. When you attach a Magic Keyboard, external mouse, or trackpad, all native cursor events, hover states, right-clicks, and keyboard shortcuts work identically to macOS and Windows.

01 / Floating Dock (⚙️)

Draggable Tool Pill

Press and drag the subtle ⚙️ button anywhere along the screen edges—each app remembers your preferred spot. Tap to open quick buttons for ↩️ Undo, ↪️ Redo, ⌫ Delete, Right-Click, ⌨️ Keyboard, and 🔄 Instant Cloud Reload.

Position Saved in LocalStorage
02 / Procreate Gestures

Multi-Touch Shortcuts

Work without a physical keyboard effortlessly: Two-finger quick tap triggers Undo (Ctrl+Z), Three-finger quick tap triggers Redo (Ctrl+Y), and Two-finger pinch smoothly zooms the canvas in or out.

100% Passive Touch Listeners
03 / Native Files Bridge

Save to iPadOS Files

Exporting a PSD, SVG, DOCX, XLSX, PDF, WAV, or DXF automatically invokes the native iPadOS Share & Save to Files sheet so you can save directly to iCloud Drive, On My iPad, or AirDrop, backed by persistent browser storage.

Web Share Level 2 + Storage Lock
04 / Status Bar Layout

Precision Top Menu Offset

Precision-tuned 18px top safe-area offset in Safari Home Screen mode keeps the iPadOS clock and battery bar from overlapping the top menu bar (File Edit Image Layer...), or 0px edge-to-edge in the native .ipa.

Auto-Detected Standalone Mode
04 / Installation & Auto-Update Guide
Choose Cloud Web App (No PC) or Native .IPA Sideload
Option A — Cloud Web App (Recommended)
No PC Required
  1. 01
    Open this page in Safari on your iPad, iPad Air, iPad mini, or iPad Pro.
  2. 02
    Tap Launch on any of the 13 applications above and wait a moment for the workspace to appear.
  3. 03
    Tap the Safari Share button (square with upward arrow) and select Add to Home Screen.
  4. 04
    Automatic Updates: Our GitHub Actions bot checks @storytold every Sunday at 03:00 UTC. Tap ⚙️ → 🔄 inside any app to pull the newest build immediately.
Option B — Native .IPA Sideload
Zero Status Bar · Offline
  1. 01
    Tap ↓ .IPA on any app card above (or visit GitHub Releases) to download <AppName>-iPad.ipa.
  2. 02
    Import and sign the .ipa directly on your iPad using Feather, ESign, GBox, SideStore, or Sideloadly.
  3. 03
    Enjoy true edge-to-edge fullscreen with the iPadOS Status Bar & Home Indicator hidden and 100% offline WebAssembly execution.
  4. 04
    Whenever upstream releases a new version, run the Build All 13 Native iPadOS (.ipa) Apps workflow in GitHub Actions to generate fresh .ipa installers.
